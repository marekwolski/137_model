# Delivering the Digital Workplace

- building platforms, products and services across the Capability Areas
- products and services are what the user base sees and uses
- Products are technology that users use directly
- Services are where human beings (or AI Agents too now) are involved
- in the Infrastructure space, many products will simply expose the features and functions of underlying platforms (well-integrated)
  - in this case, the product will also represent option choices from the underlying platforms
- there may also be distinct products that are in-house applications
  - these would be delivered using the Product Operating Model

- a version of the Value Proposition Canvas
