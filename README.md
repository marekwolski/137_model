# Marek’s reference model for the modern digital workplace

This GitHub repo is home to my 1-3-7 reference model for the modern digital workplace.

It addresses the scope and purpose of the modern digital workplace, the three Outcome Domains or "Experiences" through which we can decide what good needs to look like and describes the seven Capability Areas that exist in any worthwhile modern digital workplace.

Start here for the [Introduction](https://137model.wolski.me.uk/introduction).

I decided to write this guide after failing to find anything like it:

- that wasn't compromised by the need of a vendor to sell their stuff

- or skewed by someone dazzled by the latest wizzy thing.

I work as a Chief Architect for a systems integrator on a large digital workplace services contract. It's my job to collect **all** the pieces for solutions that are required and knit them together into something **that works for all the stakeholders**.
